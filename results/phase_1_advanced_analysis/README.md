# Advanced Analysis

This folder contains additional post-processing analyses used to better interpret the mechanical behavior of the different interface models.

## Contents

- `stress_gradient_comparison.png` → first derivative of S11 along the line
- `stress_curvature_comparison.png` → second derivative of S11 along the line

## Purpose

These analyses help evaluate how abruptly the stress field changes near the interface and provide additional insight into load transfer smoothness.

## Notes

These plots are intended as advanced interpretation tools and are supplementary to the main S11 comparison figures.
