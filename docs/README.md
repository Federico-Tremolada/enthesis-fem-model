# Documentation

This folder contains the technical documentation of the project, describing the modeling strategy, assumptions, and analysis pipeline used to study stress distribution in the tendon–bone interface.

---

## Structure

### Phase 1 — Model Development

* `phase_1_overview.md` → objectives and general strategy
* `phase_1_modeling.md` → model definitions and material laws
* `phase_1_postprocessing.md` → stress extraction and comparison

---

### Phase 2 — Model Refinement and Validation

* `phase_2_overview.md` → refinement strategy and objectives
* `phase_2_modeling.md` → model improvements and parameter studies
* `phase_2_postprocessing.md` → stress and energy-based analysis

---

### General

* `fem_setup.md` → geometry, materials, boundary conditions, and simulation setup

---

## Purpose

The goal of this documentation is to:

* provide a clear and structured description of the modeling approach
* ensure reproducibility of the simulations
* justify modeling choices and assumptions
* support the interpretation of results

---

## Notes

This documentation complements:

* `models/` → visual and descriptive representation of each model
* `scripts/` → data extraction and analysis tools
* `results/` → processed data and figures

Together, these components form a complete and reproducible FEM workflow.
